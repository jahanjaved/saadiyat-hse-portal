ALDAR OSH INSPECTION REPORT GENERATOR - SMART DYNAMIC ACTION ENGINE

Updated final version:

1. Manual observation comments now drive all three report fields:
   - Observation Description
   - Immediate Action Taken
   - Action to be taken as agreed, but not limited to

2. The system now creates scenario-specific immediate and preventive actions instead of generic text.

3. Added specific logic for examples such as:
   - JCB broken glass / damaged windscreen / broken cabin glass
   - unsafe ladder
   - scaffold/access platform issues
   - electrical DB/cable issues
   - excavation/trench issues
   - welfare issues
   - edge protection/openings/rebar
   - fire/storage issues
   - traffic/man-machine interface
   - lifting/precast
   - plant/equipment defects

4. For JCB broken glass, the system now includes:
   - stop and remove equipment from operation
   - isolate and clean broken glass using PPE
   - plant maintenance inspection
   - repair/replace damaged glass
   - verify operator visibility and cabin integrity
   - update equipment checklist and defect reporting
   - inspect similar plant/equipment
   - brief operators and supervisors
