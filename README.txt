ALDAR OSH INSPECTION REPORT GENERATOR - DEEP SMART MANUAL OBSERVATION UPDATE

Updated as requested:

1. Manual comments are now treated as the main source when entered.
2. If Observation Category is selected as Other but the manual text says "unsafe ladder", the system now detects it as a ladder / work at height issue.
3. The system no longer uses generic scaffold wording for ladder comments.
4. For short notes such as:
   - unsafe ladder
   - open DB
   - poor cable management
   - no cold drinking water
   - no edge protection
   - excavation without barricade
   the system creates specific wording for:
   - Observation Description
   - Immediate Action Taken
   - Action to be taken as agreed, but not limited to
   - Likely Root Cause
   - Legal / Other Requirements
5. Unsafe ladder wording now includes ADOSH CoP 37.0 - Ladders and ADOSH CoP 23.0 - Working at Heights.
6. Manual comments can still be edited after auto-generation before producing the Word file.
